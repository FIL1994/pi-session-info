:::caution[Early Linux process inventory]
Current discovery lists current-user processes with the exact `pi` title.
Session identity, model, and activity remain unknown. Extension-backed telemetry,
history, and watch mode are planned, not implemented.
:::

## A small tool with clear boundaries

<CardGrid>
  <Card title="One local snapshot" icon="terminal">
    Run the Bun CLI for a tab-separated overview or JSON. On Linux, discovery reads `/proc`.
  </Card>
  <Card title="Inside Pi" icon="open-book">
    Explicitly load the extension and use `/sessions` for the same read-only inventory, without adding it to model context.
  </Card>
  <Card title="Unknown means unknown" icon="magnifier">
    A process is not an exact conversation mapping. No activity is inferred from old transcripts.
  </Card>
  <Card title="Private by design" icon="shield-check">
    No transcript reads, model calls, daemon, status publishing, or automatic installation in the current observer.
  </Card>
</CardGrid>

## Try the synthetic preview

From the repository root:

```sh
bun install
bun run demo
```

Demo paths, PIDs, session IDs, models, and activity are fictional. The preview is
useful on platforms without Linux discovery, but it is never evidence of live sessions.
